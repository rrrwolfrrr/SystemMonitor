📖 Введение

Добро пожаловать!

SystemMonitor — программа для мониторинга вашего компьютера в реальном времени. Она показывает температуры, загрузку, частоты и состояние всех компонентов ПК на удобном веб-дашборде в стиле ретро Windows 95.

Поиск проблем с датчиками
ℹ️ Требования: Windows 10/11 (64-bit), .NET Framework 4.8+. Программа должна работать от имени администратора — это нужно для чтения датчиков материнской платы.
🚀 Установка

Установка программы

  1. Запустите файл установщика SystemMonitor_Setup.exe.
  2. Если появится окно защиты Windows — нажмите «Подробнее» → «Выполнить в любом случае».
  3. Следуйте подсказкам мастера установки.
  4. При желании отметьте дополнительные опции:
    • 🖥️ Создать ярлык на рабочем столе
    • ⚡ Автозапуск при старте Windows
    • 🔥 Открыть порты в брандмауэре (для доступа с других устройств)
  5. Нажмите «Установить» и дождитесь завершения.
  6. В финальном окне оставьте галочки «Запустить SystemMonitor» и «Открыть дашборд в браузере» — нажмите «Готово».
⚠️ Установка требует прав администратора — без них программа не сможет читать датчики температуры и вентиляторов.
✅ По умолчанию программа устанавливается в C:\Program Files\SystemMonitor.
🖥️ Первый запуск

Что происходит при запуске

После запуска программы:

  • 🔸 В системном трее (возле часов) появляется иконка программы.
  • 🔸 В браузере автоматически открывается дашборд с данными.

Если браузер не открылся — откройте дашборд вручную, введя адрес:

http://localhost:5000/dashboard

🔐 Права администратора

Почему это важно

Для чтения датчиков материнской платы, вентиляторов и точных температур процессора программе необходим прямой доступ к аппаратным регистрам. Это доступно только с правами администратора.

Что работает БЕЗ прав администратора

  • ✅ Загрузка CPU (через системные API)
  • ✅ Использование оперативной памяти
  • ✅ Сетевой трафик
  • ✅ Свободное место на дисках

Что НЕ работает без прав администратора

  • ❌ Температуры материнской платы
  • ❌ Обороты вентиляторов (RPM)
  • ❌ Напряжения платы (+12V, +5V, Vcore)
  • ❌ Точные температуры процессора по ядрам
🔴 Обязательно: запускайте программу от имени администратора. Иначе карточки вентиляторов и материнской платы будут пустыми!

Как включить постоянный запуск от администратора

  1. Найдите ярлык SystemMonitor на рабочем столе
  2. Правый клик → Свойства → вкладка Совместимость
  3. Поставьте галочку «Выполнять эту программу от имени администратора»
  4. Нажмите Применить

⚡ Автозапуск при старте ПК

Кликните по пункту — появится галочка ✓. Теперь программа будет запускаться вместе с Windows. Повторный клик отключает автозапуск.

🌐 Открывать дашборд при запуске

Если галочка стоит — при запуске программы браузер сам откроет дашборд. Если снять галочку — программа будет работать «тихо», только в трее. Удобно для фонового мониторинга.

✅ Обе настройки сохраняются и действуют после перезагрузки компьютера.
📊 Дашборд

Обзор дашборда

Дашборд состоит из карточек — каждая отвечает за свой компонент компьютера:

КарточкаЧто показывает

🎮 GPUТемпература, загрузка, частота, видеопамять, мощность
🧠 ПамятьЗанято / всего, процент использования RAM

🌀 ВентиляторыОбороты всех кулеров (RPM)
🔌 Материнская платаНапряжения и температуры платы
🧩 Прочие датчикиВсе остальные датчики системы

🌡️ Температура по ядрам CPU

В карточке CPU есть выпадающий список — выберите «Все ядра» или конкретное ядро (Core #1, Core #2…), чтобы видеть его температуру отдельно.

📊 Эффективная частота CPU

На новых процессорах (AMD Ryzen 3000+, Intel 12th Gen+) показывается реальная эффективная частота с учётом C-states (спящих режимов ядер).

На старых процессорах (Intel Haswell и раньше) это поле может быть пустым — такие CPU не предоставляют эту метрику. Это нормально, не является ошибкой.

ℹ️ Данные обновляются автоматически раз в секунду. Ничего нажимать не нужно.
🎛️ Работа с карточками

Настройка под себя

  • 🖱️ Перемещение: зажмите заголовок карточки и перетащите её в нужное место.
  • 📐 Размер: потяните за уголок карточки, чтобы изменить её размер.
  • 👁️ Скрыть датчик: в настройках карточки можно скрыть ненужные датчики или переименовать их.
  • ➕ Своя карточка: добавьте пользовательскую карточку с любым датчиком из раздела «Прочие».
  • 🔒 Блокировка: кнопка в панели зафиксирует расположение карточек.
  • 💾 Сохранение: расположение карточек запоминается автоматически и восстановится при следующем запуске.
✅ Случайно «сломали» интерфейс? В настройках есть кнопка сброса к виду по умолчанию.
🎨 Темы и пресеты

Внешний вид

  • 🎨 Темы: откройте редактор тем и выберите готовую палитру (светлая, тёмная, ретро-CRT и др.) или создайте свою — цвета, градиенты, шрифты.
  • 💾 Пресеты: сохраните текущую расстановку карточек и тему одним кликом. Переключайтесь между пресетами мгновенно.
  • 📤 Экспорт / импорт: пресет можно выгрузить в файл и перенести на другой компьютер или поделиться с другом.
ℹ️ Любителям ретро: включите CRT-эффект — сканлайны и мерцание как на старых мониторах!
📱 Мобильная версия

Следите за ПК со смартфона

Мобильная версия — лёгкая и быстрая, специально для маленьких экранов.

  1. Убедитесь, что телефон и компьютер в одной Wi-Fi сети.
  2. Узнайте IP компьютера: на ПК нажмите Win+R → введите cmd → команда ipconfig.
  3. Откройте в браузере телефона адрес (пример):
http://192.168.1.100:5000/mobile
⚠️ Если страница не открывается — разрешите программу в брандмауэре (пункт был при установке) или добавьте правило вручную для портов 5000 и 8765.
🔴 Важно: всегда используйте http://, а не https://. Программа работает только по незашифрованному протоколу.
📈 История и логи

История метрик

Страница «История» показывает графики температур и загрузки за выбранный период: 5 минут, 1 час, 6 часов, 24 часа. Удобно отслеживать перегрев после чистки ПК или разгона.

Данные можно экспортировать в CSV для анализа в Excel или других программах.

Логи

Страница «Логи» — журнал событий сервера. Поможет разобраться, если что-то пошло не так: здесь видны ошибки и предупреждения. Есть фильтр по уровню и кнопка очистки.

ℹ️ Логи также пишутся в файл server.log в папке установки — можно открыть его в любом текстовом редакторе.
🌐 Доступ по сети

Доступ с других устройств

SystemMonitor доступен не только на самом компьютере, но и с любого устройства в вашей локальной сети — телефона, планшета, второго ПК.

http://ВАШ_IP:5000/dashboard
⚠️ Безопасность: не открывайте доступ к программе из интернета. Программа предназначена только для домашней локальной сети и не имеет пароля.
🔍 Диагностика

Если датчики не отображаются

В программу встроена мощная система диагностики, которая покажет, какие датчики видит библиотека на вашем компьютере.

Шаг 1: Закройте другие программы мониторинга

Следующие программы могут блокировать доступ к датчикам:

  • ASUS AI Suite / Fan Xpert
  • HWiNFO64
  • AIDA64
  • SpeedFan
  • Open Hardware Monitor
  • Corsair iCUE, NZXT CAM, MSI Afterburner

Закройте их через трей или Диспетчер задач перед запуском SystemMonitor.

Шаг 2: Посмотрите базовую диагностику

Просто запустите программу и откройте страницу «Логи». Найдите блок:

ДИАГНОСТИКА ОБОРУДОВАНИЯ (однократно при старте) ====================================================================== Оборудование: тип=Motherboard, имя=ASUS ..., сенсоров=0 Оборудование: тип=SuperIO, имя=Nuvoton NCT6791D, сенсоров=6 Оборудование: тип=Cpu, имя=Intel Core i7-4770K, сенсоров=35 Оборудование: тип=GpuNvidia, имя=NVIDIA GeForce GTX 1050 Ti, сенсоров=27 ======================================================================

Если видите SubHardware: тип=SuperIO — вентиляторы и датчики платы работают корректно.

Шаг 3: Расширенная диагностика (для продвинутых)

Если нужно увидеть каждый датчик отдельно с именем и значением:

  1. Создайте файл diagnostic.bat рядом с SystemMonitor.exe:
    @echo off set DIAGNOSTIC=1 start SystemMonitor.exe
  2. Запустите diagnostic.bat от имени администратора.
  3. Откройте http://localhost:5000/logs — в логах будет список всех датчиков с их значениями.
✅ По логам диагностики можно точно понять, какие датчики видит библиотека и почему некоторые из них не отображаются на дашборде.
❓ Частые вопросы

Вопросы и ответы

Карточки пустые / нет данных с датчиков
Программа должна быть запущена от имени администратора. Закройте её через трей («Выход») и запустите ярлык правой кнопкой → «Запуск от имени администратора». Также проверьте, что антивирус не блокирует программу и нет запущенных ASUS AI Suite, HWiNFO64, AIDA64.
Не вижу иконку в трее
Windows прячет новые значки. Нажмите стрелку ⌄ возле часов — иконка там. Её можно перетащить на видимую панель.
Дашборд не открылся при запуске
Откройте браузер и введите http://localhost:5000/dashboard. Если страница не грузится — проверьте, запущена ли программа (иконка в трее). Возможно, в трее выключена опция «Открывать дашборд при запуске» — тогда открывайте вручную или через меню трея.
Браузер выдаёт ошибку при открытии с телефона
Убедитесь, что вы используете http://, а не https://. Современные браузеры часто автоматически подставляют https для локальных IP. Введите адрес вручную или откройте в режиме Инкогнито. В логах сервера эта ошибка выглядит как code 400, message Bad request version — это не баг программы.
Антивирус ругается на программу
Это ложное срабатывание на неподписанный .exe — частое явление для домашних программ. Добавьте папку установки в исключения антивируса.
Порт 5000 занят другой программой
Откройте файл env.env в папке программы и измените значение SERVER_PORT на другое (например, 5001). Перезапустите программу.
Как добавить программу в автозагрузку?
Правый клик по иконке в трее → «Автозапуск при старте ПК». Появится галочка ✓ — готово. Повторный клик отключит автозапуск.
Температуры не показываются, но загрузка видна
Значит, программа запущена без прав администратора или работает конкурирующая программа мониторинга (ASUS AI Suite, HWiNFO64). Закройте их и перезапустите SystemMonitor от имени администратора.
Вентиляторы не отображаются
Вентиляторы читаются через чип SuperIO на материнской плате. Это требует: 1) прав администратора; 2) отсутствия конкурирующих программ мониторинга; 3) иногда — отключения ASUS AI Suite в BIOS. Проверьте раздел «Диагностика» выше.
Поле «Частота (эффект.)» пустое на CPU
Это нормально для старых процессоров (Intel Haswell и ранее). Они не предоставляют эту метрику через системные регистры. Эффективная частота отображается только на современных CPU (AMD Ryzen 3000+, Intel 12th Gen+).
Программа не удаляется полностью
Перед удалением закройте программу через трей («Выход»). Затем удалите через «Параметры → Приложения». Установщик автоматически удалит все файлы, правила брандмауэра, ключи реестра и пользовательские данные.
Хочу сбросить все настройки
Откройте дашборд в браузере → нажмите кнопку сброса макета в панели инструментов. Это вернёт карточки в расположение по умолчанию. Темы и пресеты сохраняются отдельно.
🗑️ Удаление

Как удалить программу

  1. Закройте программу: правый клик по иконке в трее → «Выход».
  2. Откройте Параметры → Приложения → Установленные приложения (или «Панель управления → Программы и компоненты»).
  3. Найдите SystemMonitor → Удалить.

Удалитель автоматически закроет программу, уберёт правила брандмауэра, ключ автозапуска из реестра, пользовательские данные (темы, историю, логи) и все установленные файлы.

ℹ️ Либо запустите удаление через меню Пуск: Пуск → SystemMonitor → Удалить SystemMonitor.
✅ После удаления на вашем компьютере не останется следов программы — ни файлов, ни записей в реестре, ни правил брандмауэра.
