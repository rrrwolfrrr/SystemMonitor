⚠️ Предупреждения по температуре

Установите пороги CPU и GPU для каждого компьютера, а также отдельный порог для каждого обнаруженного накопителя. Для GPU учитывается более высокая основная температура или Hotspot. Для новых дисков порог по умолчанию — 70 °C; пустое поле отключает предупреждение.
